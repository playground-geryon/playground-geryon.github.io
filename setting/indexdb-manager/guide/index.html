IndexedDB 백업/복원/삭제 관리

소개

브라우저에 저장된 IndexedDB를 백업/복원/삭제합니다.

가이드
데이터베이스 목록
현재 브라우저의 IndexedDB 목록을 확인합니다.
  • 새로고침으로 목록 갱신
  • 스토어 목록 확인
결과: DB별 버전/용량/레코드 수가 표시됩니다.
백업 다운로드
선택한 스토어만 백업 파일로 내보냅니다.
  • 스토어 체크
  • [백업 다운로드] 클릭
결과: JSON 백업 파일이 저장됩니다.
불러오기/병합
백업 파일을 불러와 선택 항목만 병합합니다.
  • 백업 파일 선택
  • 스토어 체크
  • [선택 항목 병합] 클릭
결과: IndexedDB에 데이터가 추가/병합됩니다.
삭제
선택한 데이터베이스를 삭제합니다.
  • [삭제] 클릭
  • 확인
결과: 해당 DB가 삭제됩니다.
